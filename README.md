# Ley Line of Angel · 천사맥(天使脈)

GitHub Pages에 공개할 수 있는 정적 웹게임 프로젝트예요. 플레이어는 공개된 웹 주소에 접속하기만 하면 돼요. 플레이어 측 설치, BAT 실행, Python 설치, 게임 파일 다운로드는 필요하지 않아요.

## 제작 표기

시작 화면 아래쪽에 제작 표기가 들어 있어요. 텍스트 & 기획은 제작자, 번역은 기계 번역 및 AI 번역, 코딩은 GPT와 Claude로 적혀 있어요. 표기 문구는 `js/core/i18n.js`의 `credit…` 키와 `index.html`의 `intro-credits` 블록에서 수정할 수 있어요.

## 시작 화면

게임을 열면 먼저 시작 화면이 나와요. 장르(단편 조사형 텍스트 어드벤처), 예상 플레이 시간, 내용 주의 문구를 보여주고, `시작하기`를 누르면 본 게임이 시작돼요. `저장 파일로 이어하기`로 JSON 저장 파일을 바로 불러올 수도 있어요. 문구는 `js/core/i18n.js`의 `introSummary`, `introWarning`(일본어·한국어 각각)을 수정하면 돼요.

## 지금 바로 게임을 열어보는 방법

- `preview.html`을 더블클릭하면 게임을 바로 확인할 수 있어요.
- 이 파일은 CSS와 JavaScript를 하나의 HTML에 포함한 미리보기용 파일이에요. Python, BAT, GitHub가 필요하지 않아요.
- 실제 개발용 원본은 `index.html`, `css/`, `js/`로 분리되어 있어요. 원본의 모듈 파일은 브라우저의 로컬 파일 보안 정책 때문에 `file://`로 직접 열면 제한될 수 있어요.
- 공개할 때는 미리보기 파일이 아니라 분리된 원본 프로젝트를 GitHub Pages에 올리는 방식을 권장해요.

## GitHub Pages 공개 방법

1. 이 폴더 안의 파일 전체를 GitHub 저장소의 최상위(root)에 올려요.
2. 저장소의 **Settings → Pages**로 이동해요.
3. **Build and deployment → Source**에서 **Deploy from a branch**를 선택해요.
4. Branch는 `main`, 폴더는 `/ (root)`로 지정하고 저장해요.
5. GitHub Pages가 공개한 URL에 접속하면 게임이 실행돼요.

이 프로젝트는 HTML, CSS, JavaScript 모듈만 사용하는 정적 사이트예요. 서버 코드나 배포 빌드 과정이 필요하지 않아요. 저장소의 폴더 구조와 파일 경로를 그대로 유지해 주세요. `.nojekyll` 파일도 루트에 포함되어 있어요.

## 언어 설정

- 첫 화면은 일본어예요.
- 화면 오른쪽 위의 언어 전환 버튼으로 일본어와 한국어를 바꿀 수 있어요.
- 새로 추가한 2차 조사 문구의 일본어는 한국어 원문을 바탕으로 작성한 번역 초안이에요.
- 진행 중인 언어 설정은 JSON 세이브 파일에도 저장돼요.

## 조사 단계와 진행률

한 번의 플레이 안에서 1차 조사와 2차 조사를 순서대로 진행해요. 별도의 2회차 플레이를 요구하지 않아요.

- **1차 조사:** 장소 14곳을 각각 한 번 조사하고, 획득한 아이템 2종도 개별 조사해요.
- **초기 보고서:** `천사의 생태`는 1차 조사율 28~32%, `대상인 제물을 확보하는 경로`는 33~37% 사이에서 해금돼요. 새 게임마다 범위 안에서 임계치가 정해져요.
- **2차 조사 해금:** 초기 보고서 두 편을 연구 기록 화면에서 실제로 열람하면 2차 조사가 활성화돼요.
- **2차 조사:** 과수원, 신전 지하, 무덤가, 재가 쌓인 곳, 우물가를 다시 방문해 조사해요. 보고서 열람 순간 해당 장소에 서 있더라도, 다른 장소로 이동했다가 다시 돌아와야 해요.
- **후반 보고서:** `축제에 관하여`는 종합 조사율 86~90%, `'천사'에 대하여`는 95~98% 사이에서 해금돼요.
- **100% 조건:** 1차 장소 14개 + 2차 장소 5개 + 아이템 2종, 총 21개 조사 항목을 모두 완료해야 해요. 5번째 보고서 `침입 및 기생 경로`는 100% 계산에 포함되지 않고 엔딩 이후 보너스로 공개돼요.

## 지도 연결 구조

- 외곽은 광장과 숲에 연결돼요. 광장에서 학교, 탑, 민가, 화려한 집, 신전, 우물가로 이동할 수 있어요.
- 민가는 광장과 우물가에 연결되고, 우물가를 통해 과수원으로 갈 수 있어요.
- 신전은 광장, 신전 지하, 무덤가, 재가 쌓인 곳에 연결돼요. 무덤가와 재가 쌓인 곳도 서로 연결돼요.
- 숲은 외곽과 절벽에 연결돼요. 절벽은 일반 조사 장소 중 하나이며, 마지막 엔딩을 자동으로 시작하지 않아요.

## 저장 방식

게임 안의 `JSON 저장` 버튼으로 진행 상황을 파일에 저장하고, `JSON 불러오기` 버튼으로 복원해요. 브라우저 저장 공간에는 게임 진행 상황을 자동 저장하지 않아요.

저장 파일에는 현재 위치, 방문·조사한 장소, 1차·2차 조사 상태, 2차 조사 대상지 재방문 여부, 읽은 초기 보고서, 소지품, 아이템 조사 여부, 현장 기록, 조건부 기록, 무작위 보고서 공개 임계치, 엔딩 선택 상태, 언어 설정이 포함돼요. 기존 저장 형식도 불러올 수 있도록 호환 처리를 유지해요.

## 개발용 테스트

`npm test`는 제작자가 개발 환경에서 게임 로직을 확인할 때만 사용하는 선택 기능이에요. Node.js가 필요하지만, 플레이어에게는 필요하지 않아요.

- `npm test`: 게임 로직, 문구 연결, 저장 형식을 확인해요.
- `npm run build:preview`: `index.html`, `css/`, `js/`를 하나로 합쳐 `preview.html`을 새로 만들어요. 원본을 수정한 뒤에는 이 명령으로 미리보기 파일을 갱신해 주세요. 처음 한 번은 `npm install`이 필요해요.

## 엔딩 문구의 표기 규칙

- 한국어 엔딩의 띄어쓰기 없는 독백은 일본어에서 띄어쓰기가 연출 수단이 되지 못하므로, 일본어 판에서는 같은 구간을 전부 가타카나로 표기해요.
- 이 구간을 수정할 때는 `js/data/endingScene.js`의 `accept.ja`에서 `ワタシハ…`로 시작하는 줄을 고치고, 가타카나 외의 문자가 섞이면 `npm test`가 알려줘요.
